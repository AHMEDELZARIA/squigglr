\section{MIS of the Audit Log Module (\mref{mLog})}
\label{sec:mLog}

\subsection{Module}

AuditLog

\subsection{Uses}

None.

\subsection{Syntax}

\subsubsection{Exported Constants}

None.

\subsubsection{Exported Types}

\begin{itemize}
\item EventKindT $= \{\mathit{signInFailed}, \mathit{sessionTimeout},
\mathit{changeRefused}\}$, the security events that are logged: a failed
sign-in and a session timeout (NFR-SEC-005), and a refused change to a saved
record (NFR-SEC-003).
\end{itemize}

\subsubsection{Exported Access Programs}

\begin{accessprograms}
log & $e$: EventKindT, $a$: AdultIdT $\cup$ $\{\bot\}$, $\mathit{about}$:
string & -- & -- \\
\end{accessprograms}

\subsection{Semantics}

\subsubsection{State Variables}

None.

\subsubsection{Environment Variables}

\begin{itemize}
\item $\mathit{auditLog}$: the server-side store of audit events, each with its
kind, adult, subject and time.
\item $\mathit{clock}$: DateTimeT, the current time.
\end{itemize}

\subsubsection{Assumptions}

\begin{itemize}
\item $\mathit{about}$ names what the event concerns, such as the email
entered or an item's identifier. It never holds a password or the contents of a
record (NFR-SEC-003).
\end{itemize}

\subsubsection{Access Routine Semantics}

The full semantics are given in Revision~0. In brief, \texttt{log} adds the
event $(e, a, \mathit{about}, \mathit{clock})$ to $\mathit{auditLog}$, with $a
= \bot$ when no adult is known, as for a failed sign-in with an unknown email.
No access program of \progname{} reads $\mathit{auditLog}$, so no adult can see
it (NFR-SEC-005).

\subsubsection{Local Functions}

None.
